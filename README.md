# Генератор кода с авторизацией

Простой веб-сервис на Python и Flask. После входа показывает случайный четырёхзначный код от 1000 до 9999. При обновлении страницы снова требуется вход.

Демонстрационные логин и пароль: **demo / demo**, также указаны на форме. Авторизация действует только на один запрос выдачи кода, сессия не сохраняется.
